# 2026-10-01 설계 인계

## 확정된 선택

공용 서버 없이 팀원별 PC에 독립 설치. 각자 브라우저 이용과 개인 커스텀. Docker의 설치 재현성은 활용하되 기존 GPU 학습을 강제로 컨테이너화하지 않는다. 폴더 개선과 Codex/Claude용 문서·handoff·AGENTS를 마련한다. RAG/MCP는 필수가 아니며 현재는 보류한다.

- Kaggle skill로 credential 존재 여부만 확인했다. 비밀값을 출력하지 않았다.

- 프로젝트 진입 문서, 전략/아키텍처, AI 환경, ADR, backlog, 이동 계획, 설정 예제를 만들었다.
