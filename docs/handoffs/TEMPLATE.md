# 작업명

갱신: YYYY-MM-DD HH:mm KST. 작업ID: 식별자. 상태: 진행/완료/실패/보류/차단 중 하나. 담당: 역할·세션ID.

## 요청·결과

- 요청: 이번에 허가된 목표·범위와 달라진 조건.
- 결과: 실제 변경·관측한 사실과 파일/산출물 링크.
- 결정: 판단 이유·적용 범위. 관련 교훈 ID가 있으면 연결.

## 검증·한계

- 검증: 실행한 명령·결과 또는 관측 근거. 미실행 항목은 구분.
- 한계: 미확인·실패·보류 조건. 프로세스 종료를 성능 향상으로 기록하지 않는다.

## 다음·재개

- 다음: 담당·후속 1~3개 또는 없음. 다음 가설은 plan에 연결.
- 실행 중일 때만: ID/PID·로그/receipt·ETA·재개/중단 명령·예약 결과.
- 재사용·제한: 완료 결과·승인 범위·반복 금지·재검토 조건.

사용 시 안내 문구와 불필요한 빈 항목은 제거한다. 실제 상태가 바뀌거나 인계할 때 기록하고, 시간 경과에 따른 갱신은 하지 않는다. 작은 변경은 3~5줄로 합칠 수 있다. 최대 2000자/50줄이며 상세는 evidence로 연결한다. [문서 규격](../runbooks/handoff-maintenance.md).
