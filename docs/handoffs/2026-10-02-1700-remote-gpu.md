## 고친 결함

1. T4 OOM → 로컬 R1 계획에도 `--grad-ckpt` 추가, 큐 재시작.
2. 출력에 workspace 중복 → Kaggle은 `/tmp`에서 학습, `results/<TAG>`만 저장.
3. 결과 데이터셋 하나를 덮어쓰면 병렬 결과 소실 → 실행마다 비공개 데이터셋.
4. 32 GB 단일 zip은 디스크 2배 필요 → 파일 단위·이어받기. Windows symlink 실패 시 30 GB 복사하던 fallback 제거.
5. **label/split hash가 OS 줄바꿈에 따라 달라** 로컬·원격이 비교 불가로 표시 → LF 고정(`lf-v2`). EXP060은 완료 직후 큐의 `EXP060_REHASH`가 재계산(이전 값 `legacy_hashes`).
6. `raptor_infer.py --device cpu`, GPU를 숨기면 환경 기록이 실패하던 문제.
