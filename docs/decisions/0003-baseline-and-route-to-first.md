# ADR 0003 — 상위권을 위한 기준본과 개발 방향

2026-10-03 재검토. 현재 결정은 이 문서와 [실행 계획](../research/route-to-first-2026-10-03.md), [검증 규칙](0004-validation-protocol.md)을 따른다. 과거 상세는 [변경 전 원문](../handoffs/archive/snapshots/2026-10-03-direction/manifest.json)에 보존했다.

## 결정

1. **Jiweiliu Fast 2×T4 v11 / 우리 knee-anchor-0943-stack v1을 기준본으로 유지한다.** 제출56773226 public0.943, 보관본과 최신 공개본 코드23/23 일치. public 재현 기준이며 private 안정성은 미확인이다.
2. **기존 모델의 고정 추가 후보를 먼저 배포 가능한 형태로 만든다.** Raptor 전체를 교체하거나 자체 standalone0.943 초과를 전제하지 않는다. 첫 탐색안은 준비된 EXP072 5fold의 model_best.pt를 쓰는 **90% anchor +10% R2 rank blend**. 준비된5fold로 실전 연결을 점검하는 선택이며 최강 모델/최적 비율이라는 근거는 없다. 계약/parity/runtime 통과 전 제출하지 않는다.
3. **R2 누출을 제거한 작은 대조 실험과 새 입력/라벨 가설을 검증한다.** R2의 기존 weak CV 상승은 탐색 근거다. teacher/student outer 제외·fixed epoch를 먼저 지원하고, outer2개에서 시작한다. 유망할 때만5fold·추가seed·384px로 확장한다.
4. **장기 개선은 별도 영상 신호와 정답 정의 정합성에서 찾는다.** 보고서의 명시적 음성/미언급/불확실/중증도와 실제 대회 기준을 구분한다. 다음 축은 series 내부의 물리적 인접창·결측 처리 또는 다른 encoder/평면 특화 모델 중 하나다. 효과가 입증되지 않은 구조를 동시에 바꾸지 않는다.
5. **공개 LB를 최적화 루프로 사용하지 않는다.** 사전 고정한 후보만 제한적으로 제출하고 내부 안정성·domain 진단을 함께 본다. 기준본의 공개 튜닝도 불확실성으로 남긴다. public 최고점이 최종 선택의 충분조건은 아니다.

## 현재 근거와 제한

- 11:34 KST 직접 수집: 0.943, 1,129/4,943위(상위22.84%), 선두0.961. 마감10/23 08:59 KST. 0.943 유지로 순위가 유지되지는 않는다.
- [12개 최신 notebook 비교](../research/notebook-starting-point-2026-10-03.md): public0.945~0.946은 추가 자산이 현재 미확보. 같은0.943 복사본 교체의 이득은 확인되지 않았다.
- 자체 제출 확인은 EXP045 standalone0.909 한 건. 최근 Raptor/R2의 제출 점수는 없다. 보고서 기반 weak AUC와 이 점수는 직접 비교하지 않는다.
- Raptor224→384, 반복 증류, 추가seed는 자동 확장하지 않는다. 이미 수행한 작업량은 다음 실험의 채택 이유가 아니다.
- 일반 앱 기능·추가 공개노트북 전수 조사·새 대용량 데이터 확보는 현재 성능 실험에 필요한 경우로 제한한다. 우선 병목은 모델을 평가·실전 추론·제출 후보로 연결하는 과정이다.
