# ADR 0002 — 개인용 연구 중심으로 축소

2026-10-01 개인 연구 범위에 관한 사용자 결정. 2026-10-05 명확화: 최신 사용자 요청·승인과 [AGENTS](../../AGENTS.md)를 따르며, 이 문서는 해당 범위의 결정 근거다. STATE는 현황 참고 자료이며 지시의 우선순위를 정하지 않는다.

- 각 PC에서 독립 사용하는 브라우저 프로그램. 공용 서버와 사용자 관리 없음.
- Python 수집기 때문에 실행 중 localhost 연결이 필요하다. 외부에 공개하지 않고 KneeOps.cmd로 시작한다.
- 아이디어 보드·팀 공유 bundle을 제외한다. 제출 이력은 유지한다. 현황은 리더보드·제출 바로가기와 자료 접근 중심이다.
- 처음에는 자료 종류별로 왼쪽 메뉴를 나눴다. 2026-10-01 후속 요청으로 겹치는 기능을 6개 상위 메뉴로 통합했다. 자료 종류는 화면 안 분류 탭으로 구분하며 기존 해시 주소를 보존한다. 목록 기본, 카드 선택 가능. 본문 14–16px 중심.
- NEW는 한국 시간 기준 처음 추가한 당일만 표시한다. 추가 시각과 최근 수집 시각은 다르다.
- 유사 과거 대회와 상위권 전략을 참고하되 높은 점수순 노트북·참가자의 입상 주장·공식 LB 순위 의미를 구분한다.
- X시간마다 자동 수집할 수 있으나 앱 종료·PC 절전 중 수행하지 않는다. 기본 자동 수집 꺼짐.
- 원문 버전과 hash를 보존한다. API가 제공하지 않는 과거 버전은 접근 실패로 남긴다.
- 네이티브 실행 권장, Docker는 선택적 패키지. GPU 학습은 기존 환경에서 수행한다.
- 현재 대회 공식 문서의 영어·한국어·비교 보기를 제공한다. 번역은 AI 참고 번역으로 표시하고 원문 SHA256에 연결한다. 규칙 원문이 바뀌면 해당 버전의 번역을 검토하기 전까지 영어를 표시한다. 외부 번역 서비스나 유료 모델 API를 자동 호출하지 않는다.
