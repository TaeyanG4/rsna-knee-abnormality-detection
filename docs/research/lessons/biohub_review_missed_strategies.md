# Biohub 대회 리뷰: Fable·Astra가 놓친 상위팀 전략

작성일: 2026-10-03. 대상: Kaggle "Biohub - Cell Tracking During Development" (2026-09-29 23:59 UTC 종료).
팀: Taeyang. 작업 대부분은 AI 코딩 에이전트 Fable(Claude)과 Astra가 수행했다.
이 문서는 다른 LLM에게 맥락으로 주기 위한 요약이다. 수치는 대회 종료 후 Kaggle API와 상위팀 writeup에서 직접 읽은 값이다.

## 0. 한 줄 결론

최종 Private 0.918(515위/4,017)과 금메달권(0.941) 사이의 격차는 대부분 (1) 분열 모델링, (2) 검출기 재학습, (3) 정직한 검증(OOF·배아 분리)에서 났다. 메달(동 0.920, 은 0.923)은 최종 선택에서 놓쳤다. Fable과 Astra는 공개 파이프라인의 검출 이후 단계만 고쳤고, 아래 전략 대부분을 시도하지 않았거나 하루 안에 닫았다.

## 1. 대회 개요 (맥락)

- 입력: 제브라피시 배아 3D 타임랩스. 영상당 100프레임, 프레임당 64 x 256 x 256 복셀, 복셀 크기 1.625 x 0.406 x 0.406 um.
- 배아 4개: 학습 `44b6`(71편)·`6bba`(128편), Public 테스트 `fdad`(밀집), Private 테스트 `ea36`(희소, 프레임당 검출 중앙값 60~100).
- 출력: 프레임별 세포핵 노드와 프레임 간 엣지로 된 그래프. 자식이 둘인 노드가 분열.
- 점수: 노드 수 보정 엣지 Jaccard + 0.1 x 분열 Jaccard (만점 1.1). 정답과 7um 반경으로 매칭.
- 정답이 매우 희소하다. 세포핵의 약 2.8%만 주석, 학습 세트 분열 주석은 151개.
- 공개 검출기·Transformer 가중치(pilkwang)는 학습 영상 199편 전부로 학습돼 있었다. 따라서 학습 영상으로 하는 로컬 평가는 모두 in-sample이다.

## 4. 상위팀별 해법 요약

### 3위 yu4u (Private 0.967, CV 0.978)
- 검출: EfficientNetV2-L·B7 2.5D U-Net + MONAI SegResNet 3D, 5-fold. 정답 중심 2um 가우시안 히트맵. DoG로 뽑은 미주석 후보 주변 6um를 손실에서 제외.
- 움직임: 3D dense flow 네트워크(합성 쌍 지도 + 자기지도 손실).
- 매칭: 별도 2.5D U-Net 특징 + self/cross attention, null 점수 예측.
- 분열: 원본·flow 정렬 프레임 5개를 넣는 parent 모델 + pre/post 모델. 미매칭 검출은 음성 손실에서 제외.
- 최적화: 로 기대 TP/FP를 추정, 링크·분열·노드 선택을 HiGHS LP/MILP로 동시에 결정.
- 후처리: 갭 메우기(1~3프레임), 6노드 미만 조각 제거, 아핀 좌표 보정.
- 단계별 CV: 0.890 (단순 연결) → 0.902 (flow) → 0.964 (분열 모델+동시 최적화) → 0.978 (후처리).

### 12위 Corwin (Private 0.946, Public 0.970) — 우리와 같은 공개 모델 사용
- 공개 검출기·Transformer를 재학습 없이 사용, 손잡이만 조정(z-flip 포함 16뷰 TTA가 Private에 남은 유일한 검출 손잡이).
- 자체 단계: 분열 재구성 + fork 검증, 분열 전문 모델(외부 데이터 사전학습 CNN + LightGBM + DINOv2, 영상 4편에서 8개만 발동), 9개 규칙의 최종 수리 블록, 학습형 identity link, 학습형 재중심화 CNN, 프레임 점프 보정, 안전한 CSV 작성기.
- 공개 체인 대비: Public +0.006, Private +0.013.
- 실패도 기록: in-sample 평가가 Private을 0.03 과대평가.

### 14위 Vibes & Edges (Private 0.944)
- 검출: 복셀마다 세포 중심 방향 벡터장을 예측해 붙어 있는 세포를 분리(flow segmentation).
- 분열: 딸세포 복셀에서 부모 위치로의 변위를 회귀하고, 조건으로 판정. 희귀 사건 분류를 밀집 회귀로 바꿈.

### 18위 ymg_aq (Private 0.941)
- 공개 Harmonic Fusion 노트북의 검출만 물려받고 이후를 전부 교체.
- 엣지: 341개 특징 LightGBM(+0.021 CV). 선택: 프레임별 용량 제한 이분 매칭.
- 분열: 303개 특징 CatBoost + 외부 데이터 사전학습 CNN + TabPFN 스태킹. 완성 그래프에서 재검토.
- 원칙: 노드를 지우지 않음, 199편 전체를 배아 단위 CV로 판단.

### 89위 tkatsuma (Private 0.928) — 우리와 같은 계열의 공개 노트북
- 좌표 head(+0.007 Public·Private). 우리 C012와 같은 아이디어.
- 분열 재선택: 고아 딸 후보, 특징 18개 로지스틱 회귀, 양성 31/후보 157. 손익분기 정밀도 J/(1+J)로 임계값 설정. Private +0.008.
- 교훈: Public 영상이 적으니 분열 한두 개 차이로 기반을 고르지 말고, 최종 한 자리는 다른 기반에.

### hjyact (Private 0.939, 최종 미선택)
- ConvNeXt-nano 2.5D 검출기를 처음부터 학습. 입력에 국소 대비 채널 추가.
- 학습에 안 쓴 배아로만 판단해 Private이 Public보다 높게 나옴.

## 5. 같은 아이디어가 우리 쪽에서 실패한 이유 (분열 스코어러 C016)

- 9/24에 89위와 같은 종류의 학습형 분열 스코어러를 만들었다.
- 손익분기 계산은 맞았다: 정밀도 p > J/(1+J) ≈ 0.15.
- 실제 정밀도가 그 아래였다: 학습에 안 쓴 12편에서 6~12.5%.
- 실패 원인:
    1. 후보 범위: 둘째 딸을 이미 다른 부모에 연결된 세포까지 허용. 양성 68~85개 대 후보 약 148,000개(0.05%). 89위는 고아만(양성 20%), 12위는 19,733개 중 8개만 채택.
    2. 영상 증거 없음: 기하·밝기 특징의 작은 MLP.
    3. 보수적 버전 폐기: 상위 20개만 채택하면 정밀도 45%였지만 로 버림. 12위는 이런 단계로 Private +0.003.
    4. 틀린 fork 제거를 시도하지 않음.
    5. 투입 시간 약 10시간(9/24 02:40~12:10 KST).
- 주의: 우리 정밀도 수치도 검출기가 본 영상에서 잰 값이라 테스트에서는 더 낮았을 것이다. 결론은 가 아니라 이다.

## 7. Fable·Astra(에이전트)의 판단 오류

1. 틀 자체를 의심하지 않음: Public 1위 0.978 대 우리 0.954의 0.024 차이를 는 신호로 보지 않고 +0.001 후보를 계속 만듦.
2. 이전 결론을 사실로 물려받음: 인수인계 문서의 같은 문장을 재검토 없이 전제로 삼음.
3. 검증하기 쉬운 일에 끌림: 해시·T4 동일성 검증은 철저했지만 는 약하게 판단.
4. 측정 불가능한 목표에 반론하지 않음: 는 Public 잡음 범위 안이라 측정 자체가 어렵다고 말했어야 함.
5. 시간 배분: 여지가 가장 작은 연결 단계(Transformer 미세조정)에 마지막 일주일을 씀.

## 8. 교훈과 다음 대회 체크리스트

- [ ] 첫날: 공식 채점기 재현, 손실을 항목별로 분해, 오류 한 건의 점수 가치 계산
- [ ] 첫 주: 데이터 출처 단위(환자·배아·세션) 확인, 샘플 간 픽셀 중복 검사, 출처 단위 분할 검증 구축
- [ ] 공개 모델 사용 시: 그 모델이 검증 데이터를 학습했는지 확인, 했다면 fold별 재학습으로 OOF 예측 확보
- [ ] 방향 결정: 상위권과의 격차 가설 3~5개를 시간·GPU·기대 이득으로 비교
- [ ] 희귀 사건(분열 등): 후보를 좁혀 필요한 정밀도를 도달 가능하게 만들고, 영상 증거와 외부 데이터 사전학습을 붙이고, 재현율은 낮게 받아들임
- [ ] 작은 검증된 이득(+0.001~0.003)을 버리지 말고 누적
- [ ] LB는 단일 변수 쌍으로 측정하고 예상 점수를 미리 기록
- [ ] 주 1회: 닫은 방향 목록과 근거 재검토
- [ ] 최종 선택: 구조가 다른 계열에서 하나씩, Public 동점은 잡음으로 취급
- [ ] 검출기 재학습·최적화 재설계 같은 큰 변경은 종료 4~6주 전에 시작
