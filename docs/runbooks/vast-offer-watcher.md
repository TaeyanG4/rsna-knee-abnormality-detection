# Vast 한국·일본 RTX 3090 감시기

`tools/vast_offer_watcher.py`는 공식 Vast CLI 1.8.3의 공개 온디맨드 매물을 1분마다 확인하고, 조건에 맞는 최저가 매물 하나만 생성하도록 만든 재사용 프로그램이다. 설치된 Windows 작업의 실제 모드는 `tools/install_vast_offer_watcher.ps1 -Mode Status`와 작업 스케줄러 Action의 `-Mode` 인자로 확인한다. `Observe`는 공개 조회만, `Auto`는 `--once` 자동 임대·감독이다.

조건: 일본 또는 한국, 검증된 단일 RTX 3090 24GB, 호스트 RAM 32GB·유효 CPU 12코어, CUDA 12.4, 100GB 디스크, 직접 포트, 신뢰도 99%, 호스트 공시 다운로드 400·업로드 100 Mbps, 4일 이상 남은 매물, 디스크 포함 시간당 $0.175 이하, 업·다운로드 각각 $5/TB 이하. 과거 재배정 실패 머신 27157·78080은 제외한다. 최저 가격 우선, 동률이면 일본을 선택한다. 광고 대역폭은 PC→호스트 실측 속도가 아니다. 매물 가격과 계정 잔액·기존 인스턴스를 생성 직전에 다시 읽는다.

공식 CLI의 별도 최소권한 API 키를 프로젝트 밖 `~/.config/rsna-vast-watcher-v2/vastai/vast_api_key`에 둔다. 프로젝트 설정에는 키를 적지 않고 해시만 고정한다. 필요한 권한은 `misc`, `user_read`, `instance_read`, `instance_write`뿐이다. CLI 하위 프로세스의 `VAST_API_KEY`를 제거하고 전용 `XDG_CONFIG_HOME`을 지정해 대화형 CLI 키나 다른 셸 키를 읽지 않게 한다. 키 발급 후 `show user` 잔액 필드와 `show instances` 형태를 비밀 출력 없이 실확인하고, Vast의 자동충전 OFF도 확인한다.

`--dry-run`은 공개 매물만 출력한다. `--observe`는 공개 재고 변화가 생겼을 때 로컬 알림을 남긴다. `--once`는 정확히 한 임대·감독 틱이다. 생성 의도·오퍼·라벨을 로컬 `state.json`에 먼저 영속 기록하고 `--retry 1 --cancel-unavail`로 한 번만 생성한다. 응답이 불명확하면 `show instances`에서 같은 라벨을 대조하며 생성 요청을 반복하지 않는다. 생성 직후 `alert.json`과 `events.jsonl`에 ID·가격·기한을 남기고 Windows `msg.exe` 알림을 시도한다. 별도 연구 작업은 실행하지 않는다. 동일 계정에 기존 인스턴스가 하나라도 있으면 임대하지 않는다.

무감독 임대는 90분 뒤 Stop을 요청하고 2분 간격으로 실제 계약 상태를 대조한다. Stop·삭제 확인이 계속 실패하면 첫 세 번은 2분, 이후는 15분 간격으로 같은 ID에 요청하며 계속 알린다. `actual_status=exited`만으로 중지로 판정하지 않고 `intended_status=stopped`도 확인한다. 첫 임대에서는 실제 `show instances --raw` 행에 이 두 필드가 있는지 유인 감독으로 확인한다. 생성 응답을 잃으면 라벨로 대조하고, 라벨이 비었더라도 생성 직전 빈 계정에서 정확히 하나의 동일 머신 계약이 나타난 경우만 인수해 감독한다. 불명확한 생성은 다시 요청하지 않고 15분마다 경고한다. 연구 입력·SSH 접근 전에 반드시 `--retain INSTANCE_ID`로 인수해야 한다. 인수되지 않은 빈 임대는 Stop 확인 후 같은 ID를 자동 삭제해 디스크 과금을 닫는다. 인수된 임대는 삭제하지 않으며 Stop 이후 저장 비용을 담당자가 별도로 정리해야 한다. 확인된 임대만 `--extend MINUTES`로 연장할 수 있고 최초 생성부터 최대 6시간이다. 최초 $1.50 한도와 $5 잔액 보존은 등록 전 확인하며 가동 중 잔액이 $5.10 이하면 Stop을 요청한다. **PC 전원·Windows 작업 스케줄러·API가 멈추면 공급자 측 지출 상한은 보장되지 않는다.** 대여·Stop·삭제 사건은 `alert.json`과 Windows 메시지로 통보를 시도하지만 PC가 꺼지거나 사용자가 로그오프한 동안 실시간 전달은 불가능하다. Windows 메시지 창의 발신자 `Message from Taeyang`은 이 PC의 로그인 계정명이지 별도 사용자나 실제 임대 확인이 아니다. 오프라인 테스트는 데스크톱 알림을 끈 상태로 실행한다.

Windows 사용자 작업 스케줄러 설치·중지는 `tools/install_vast_offer_watcher.ps1`을 사용한다. `-Mode InstallReadOnly`는 API 키 없이 1분 공개 재고 감시를 건다. `-Mode Install`은 설정이 활성이고 키·잔액 필드·자동 빈 임대 정리가 검증되기 전에는 거부한다. `-Mode Status`는 상태를, `-Mode Uninstall`은 작업 삭제를 수행하며 계정 임대가 남았을 가능성이 있으면 삭제를 거부한다. 작업은 현재 Windows 사용자 로그인 중에만 동작한다. 기존 `rsna`와 `rsna-6` Codex 자동화는 변경하지 않는다. 운영 영수증은 `.local/vast-retry-20261008/watcher-state/`에 저장한다. 정상·재고 없음 상태는 조용하다. 이 감시기는 한 번만 임대한다. `destroyed`, `blocked`, `create_uncertain` 상태에서 새 임대를 재개하려면 계정·영수증을 확인하고 별도 검토 후 상태를 재설정해야 한다. 키를 교체하면 설정의 해시도 새 키에 맞게 갱신해야 하며 그 전에는 감독이 실패한다.
