# 중단 지시 전 지속 연구

2026-10-03 사용자 지시를 적용한다. 사용자가 중단하라고 할 때까지 RSNA Knee 성능 개선을 이어간다. 연구실 `http://127.0.0.1:8765/`의 자료·수집·다운로드·분석 도구와 로컬 자원을 활용한다. 장시간 실행만 남으면 완료 확인을 예약하고 반환할 수 있다. 이는 매번 같은 조사나 학습을 반복하거나, 결과를 기다리며 채팅을 붙잡아 두라는 뜻이 아니다.

현재 요청이 문서 검토·수정 등으로 한정되면 그 작업 범위를 따른다. 이 문서가 자동으로 연구 재개를 허가하지 않는다.

## 허가와 자원

- 허가된 조사·코드 수정·검사·로컬 소규모 실험·결과 분석은 재확인 없이 진행한다. 학습·대용량 다운로드·원격 실행은 현재 사용자 범위와 기존 허가·자원 한도를 확인한다. 중단·축소 지시가 오면 이를 우선한다.
- 자원은 로컬 GPU → 무료 Kaggle·보유 Google Plus Colab → 부족하면 비용/기대효과를 설명한 유료 요청 순서다. 무료/보유 자원도 실제 남은 할당량·실행 한도를 확인한다. 유료 지출·공개 게시의 포괄 허가는 아니다.
- 2026-10-04 사용자 후속 지시로 [준비된 후보의 제출 상시 승인](../research/submission-authorization-2026-10-04.md)을 적용한다. 후보별 확인을 반복하지 않고 정확 버전·근거·현재 한도·중복을 확인한다. 공개 게시·유료 사용은 별도 승인이다.
- 기존 EXP078의4fit 사전등록·평가기준은 그대로 둔다. 결과 검토 뒤 현재 허가 안에서 다음 실험을 새로 등록해 진행할 수 있으며,4fit 종료가 전체 연구 종료는 아니다. nested·384·추가seed를 결과와 무관하게 미리 이어 붙이지 않는다.

## 한 번의 연구 순환

1. **현황과 근거 확인:** [AGENTS](../../AGENTS.md)의 순서로 [HANDOFF](../../HANDOFF.md)→[plan](../../plan.md)→[discoveries](../../discoveries.md)→필요한 근거, `monitoring.kneeops briefing`, 실제 active job·queue·download를 확인한다. 담당 세션/agent·기존 예약·완료 산출물을 [재개 절차](handoff-maintenance.md)에 따라 대조한다. 같은 계약의 완료 결과는 재사용하고 실행 중 작업을 복제하지 않는다. 기록과 실제 상태가 다르면 먼저 차이를 기록한다.
2. **다음 가설 선택:** 소견별 오류·데이터그룹·입력·감독신호·표현/encoder·학습조건 중 개선할 문제를 하나 구체화한다. [전략 점검](strategy-review.md)으로 과거 결론·닫힌 방향·작은 이득·투자 가치를 재검토한다. 효과 없는 특정 구현과 가설 전체의 반증을 구분한다.
3. **범위 고정:** 실험ID·변경요소·라벨/분할/UID·checkpoint 선택·코드/가중치hash·GPU/시간 예산·비교/중단 기준을 사전 기록한다. 현재 학습과 겹치지 않게 한 단계만 구체화한다. 기존 원본·캐시·결과는 보존하고 새 경로를 사용한다.
4. **검사와 실행:** 기존 도구를 우선한다. 반복 조회·추출·검사·집계는 재사용 가능한 도구로 묶어 토큰과 중복 작업을 줄이고, 요약과 원 로그 위치만 회수한다. 같은 대조에 필요한run은 순차 묶을 수 있지만 큐의SUCCESS를 연구 성공으로 해석하지 않는다. 로컬 GPU 학습은1개만 실행한다. 진행 중에는 GPU를 추가 점유하지 않는 자료/CPU분석·구현을 병행할 수 있다.
5. **판정과 다음 행동:** 실제 종료·산출물·계약·수치 안정성 확인 후 사전 기준과 소견/그룹/불확실성을 함께 판단한다. 작은 양의Δ·불확실·구현실패·가설반증을 나누어 보존한다. 결과와 비용에 따라 한 단계 확대, 수정대조, 다른 가설 또는 보류를 선택하고 handoff를 남긴다. 검증 없이 자동 확대하거나 한 번의 실패로 방향을 영구 기각하지 않는다.

weak OOF·선택에 노출된 개발fold·Gold58·teacher간접누출·public LB·임상/private 성능을 계속 구분한다. 공개 모델의 검증 노출과 환자/영상중복이 확인되지 않았다면 독립 검증으로 부르지 않는다. 자세한 비교규칙은 [ADR0004](../decisions/0004-validation-protocol.md)를 따른다.

## 하루5회 제출 기회 활용

Kaggle의 하루5회는 상한이다. 서로 다른 유효한 가설을 확인할 후보가 준비되면 기회를 적극 활용하되, 횟수 소진을 목표로 삼지 않는다. **UTC00:00=한국09:00**에 일일 한도가 초기화된다. 제출 직전 live 잔여 횟수·기존 pending/완료 제출을 확인하며 오래된 briefing 숫자를 당일 잔여량으로 믿지 않는다.

각 후보는 제출 전에 가설·기준본 대비 변경·예상 방향/불확실성·실행시간·소견/그룹 근거·완성 산출물을 기록한다. UID/12target/NaN/실제reader/fallback·입력계약·offline/runtime 검사를 통과한 정확 버전과 현 한도·중복을 확인하고 상시 승인 범위에서 제출한다. 별도 승인 질문을 반복하지 않는다.

승인 후 제출ID·버전/hash·시간·사용slot을 기록한다. 채점 결과를 기다리는 반복문을 두지 않고 [도구 runbook](tools.md)의 같은채팅 heartbeat로 확인한다. 완료되면 기존 가설 대비 결과를 기록하고 내부근거·실행품질과 함께 해석한다. public 점수를 본 뒤 비율·소견별 처리를 조금씩 바꾸며 남은slot을 채우지 않는다. 다음 검증된 후보도 상시 승인 범위이며 새 근거·한도 확인은 생략하지 않는다.

## 연구실 활용과 앱 수정

`localhost:8765`의 기존 API·Store·검색·수집된 notebook/토론/실험/제출·영상/예측분석 도구를 우선 사용한다. 필요한 최신 내용만 수집하고 출처·버전·시각·범위를 남긴다. 반복되는 연구 작업이 기존 기능으로 해결되지 않으면 성능 가설/측정/자료 연결에 직접 필요한 최소 앱 기능을 수정·검증할 수 있다. 기능 개발 자체를 점수 향상으로 보고하지 않는다.

개인 연구실 범위를 유지한다. 공용서버·팀공유·아이디어보드·사용자관리·RAG/MCP 확장으로 범위를 넓히지 않는다. live DB에 별도create_app/DataManager를 만들지 않고 API·Store를 사용하며, 재시작 전 active 작업을 확인한다. 원본·캐시·이전web asset 보존과 [경로 규칙](workspace-layout.md)을 따른다.

## 장시간 작업과 반환

백그라운드 작업ID·PID/원격ID·로그·결과·관측시각·ETA·중단조건·허가된 후속을 기록한다. 조정자가 예약 도구를 사용할 수 있으면 같은 채팅 heartbeat의 첫 확인을 ETA 20분 전으로 정하고, 미완료면 갱신한 ETA에 재예약한다. 자식은 예약 정보를 조정자에게 반환한다. 도구가 없으면 자동 재개 불가와 수동 재개 명령을 기록한다. 짧은 작업은 규모에 맞는 한 번의 확인으로 처리하며 과거 시각·즉시반복 예약을 만들지 않는다.

장시간 실행만 남거나 다음 단계가 기존 승인 밖의 공개/비용 승인에 달렸다면 예약·승인할 결과물을 남기고 반환한다. 재개 시 실제 종료/산출물 확인 후 허가된 후속을 이어간다. 상태가 그대로이면 조용히 유지하고 완료·실패·사용자 판단이 필요한 변화만 알린다. 해당 작업이 끝나거나 중단되면 관련 예약을 해제한다. PC·앱 종료 중에는 예약 재개가 보장되지 않는다.

연구 시작·완료/실패·주요 결정·범위/예약 변경·인계 시 HANDOFF를 갱신한다. 정기 기록은 하지 않으며 변화가 없으면 확인 시각도 바꾸지 않는다. 계획은 plan, 교훈은 discoveries, 구현/데이터 사실은 STATE에만 기록한다. 문서 형식과 보관은 [공통 규격](handoff-maintenance.md)을 따른다.

## 토큰 복구 예약 종료 (2026-10-05 사용자 지시)

사용자는 5시간 토큰 한도 중단 복구와 예상 종료 후 이어 작업 외의 알림을 삭제하도록 지시했다. 토큰 복구 예약은 만들거나 복구하지 않는다. 실제 실행 중인 작업의 종료 ETA에 맞춘 결과 회수·이어 작업 예약만 유지하고, 결과 대기를 반복하지 않는다. PC·앱 종료나 사용량 한도로 자동 재개가 실행되지 않을 가능성은 남는다.
